## item 5 : 인덱싱보다 다중 대입 언패킹을 선호하라

```python
my_list=[10,20]
#인덱스 방식

first = my_list[0]
second = my_list[1]

#다중 대입 방식
first, second = my_list

print(first, second)
#출력 결과 : 10 20
```

- 코드를 줄일 수 있고 오히려 직관적으로 느껴지기도 한다

## item 7 : 단순한 인라인 로직에는 조건 표현식을 고려하라

```python
n=int(input())
#1
if n%2==0:
    label="짝수"
else:
    label="홀수"
#2
label="짝수" if n%2==0 else "홀수"
```

- 두가지 코드 모두 같은 기능을 하지만 코드 길이 차이가 많이 난다

## item 8 : 대입식으로 반복을 방지하라( := )

- Walrus(바다코끼리) 연산자 : 조건검사 + 변수할당 동시에 가능
- 눈과 이빨 모양이 바다코끼리와 닮아서 따왔다고 한다

```python
if (n:=len(data)) > 10:
    print(n)
  #1 변수 n에 len배열 길이 할당
  #2 조건을 만족할 경우 동작 
```
